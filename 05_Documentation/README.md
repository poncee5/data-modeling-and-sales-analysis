# Data Modeling and Sales Analysis Using Power BI

## Project Overview
This project focuses on transforming raw business data into a structured data model using Power BI. The main focus is on dimensional modeling, relationships between tables, and Dynamic Row-Level Security (RLS). A simple sales performance dashboard was also created to demonstrate how the model can support business analysis.

## Project Workflow

### 1. Data Preparation
- Reviewed and organized approximately 23 raw tables across different business areas.
- Identified related tables and grouped information logically.
- Removed unnecessary or duplicate data where appropriate.

### 2. Data Modeling
- Organized the data into fact and dimension tables.
- Established relationships between tables across sales, orders, customers, products, and security.
- Built a structured model to support data analysis.

### 3. Dynamic Row-Level Security (RLS)
- Implemented Dynamic RLS using DAX.
- Configured regional data access based on the logged-in user's email address.

### 4. Sales Dashboard
- Created a simple sales performance dashboard to demonstrate how the data model can be used for business analysis.
